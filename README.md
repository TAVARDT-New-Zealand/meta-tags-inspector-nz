# Meta Tags and Open Graph Inspector | TAVARDT New Zealand

[![Meta Tags Inspector](https://img.shields.io/badge/TAVARDT-Meta%20Tags-5b3cf5.svg)](https://tools.tavardt.com/nz/meta-tags-checker/)

Independent metadata validator for New Zealand digital assets, checking HTML title completeness, meta descriptions, and social previews.

Engineered and maintained by the digital integrity and search team at **TAVARDT New Zealand**.

***

## Metadata and Social Card Audit Capabilities

* **HTML Title and Description Analysis**: Evaluates title length and meta descriptions for New Zealand digital assets.
* **Open Graph Protocol Conformance**: Audits og:title, og:description, og:image, og:url, and og:type parameters.
* **Social Sharing Optimization**: Validates Twitter Cards for seamless preview rendering across social networks.
* **Indexation Controls**: Checks meta robots directives and canonical URL declarations.
* **Metadata Performance Score**: Standardised 0 to 100 score featuring prioritized optimization steps.

***

## Installation and Execution

Requires Python 3.8 or higher with standard library.

```bash
git clone https://github.com/TAVARDT-New-Zealand/meta-tags-inspector-nz.git
cd meta-tags-inspector-nz
python meta_inspector.py example.co.nz
```

For programmatic JSON output:

```bash
python meta_inspector.py example.co.nz -json
```
